Vicomp

Compare long codes by eye, not symbol by symbol.

Both computers must use the same options — they are part of the result.

How it works

  1. Open Vicomp on both computers.
  2. Paste the value on each, with the same options.
  3. Compare the pictures — one changed symbol changes all of them.

Fingerprint

    Each chunk gets its own symbol. The first cell that differs between the computers shows where the values differ. Point at or click a cell to highlight its characters in the value.
